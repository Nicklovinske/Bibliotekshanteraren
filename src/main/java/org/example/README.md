dynamically grow in the case that they are full. This allows for the library to accommodate a larger number of members, 
books, and loans without having to manually resize the arrays.

-the user interface aspect of the program was designed in a separate java class in order to best keep the code organised
and easy to read.

-a switch was implemented to streamline user selections. The switch makes use of a try/catch block to handle invalid
input and ensure the program continues to run without crashing.

-user searches are not case-sensitive through use of a String.toLowerCase() method, in order to make searches more
